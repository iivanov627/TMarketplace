# Архитектура фронтенда

## 1. Обзор

Фронтенд построен на **React + TypeScript + Vite** с использованием **React Router 7** для маршрутизации и **Mantine** в качестве UI-кита. Архитектура следует принципам **Feature-Sliced Design (FSD)** в упрощённом виде: код организован по бизнес-слоям с односторонним направлением зависимостей и изоляцией модулей через Public API.

## 2. Слои и структура

### 2.1. Слои

| Слой | Ответственность |
|---|---|
| `app` | Инициализация приложения, роутинг, глобальные провайдеры |
| `pages` | Полные экраны, соответствующие маршрутам |
| `shared` | Переиспользуемая инфраструктура: UI-кит, API-клиент, утилиты, конфигурация |

Слои `features` и `entities` выделяются по мере необходимости:
- `features` — когда один и тот же пользовательский сценарий (например, «добавить в корзину» или «поиск») повторяется на двух и более страницах.
- `entities` — когда одна и та же бизнес-сущность (например, «товар») используется в двух и более страницах, и у неё есть собственные UI-компоненты (карточка товара) и/или API-запросы, специфичные для этой сущности.

### 2.2. Структура папок

```text
src/
├── app/
│   ├── App.tsx               # Провайдеры (MantineProvider, BrowserRouter)
│   └── router.tsx            # Routes, Route, редиректы
│
├── pages/
│   ├── catalog/
│   │   ├── CatalogPage.tsx   # Компонент страницы
│   │   ├── api.ts            # Запросы к /products
│   │   ├── types.ts          # Типы Product, Filters
│   │   ├── components/       # Компоненты, специфичные для каталога
│   │   │   ├── ProductCard.tsx
│   │   │   └── SearchBar.tsx
│   │   └── index.ts          # Public API
│   ├── ... 				  # остальные страницы
│
├── shared/
│   ├── ui/                   # Обёртки над Mantine, общие компоненты
│   ├── api/
│   │   └── client.ts         # axios instance с interceptors
│   ├── lib/                  # Утилиты (formatPrice, date)
│   └── config/               # Константы (ROUTES, BASE_URL)
│

└── main.tsx                  # Точка входа

```

## 3. Правила импортов

1. **Направление зависимостей — строго вниз:** `app → pages → shared`.
2. **Страницы не импортируют друг друга.** Общие типы и утилиты выносятся в `shared/`.
3. **Public API через `index.ts`.** Внешний код обращается только к экспортам `index.ts` модуля.


## 4. Работа с API

- **Единый axios instance** в `shared/api/client.ts` с `baseURL: '/api'` и interceptors для авторизации.
- **Запросы** размещаются в `api.ts` соответствующего модуля (`pages/catalog/api.ts`).
- **Типы ответов** — в `types.ts` модуля. Типы, используемые двумя и более модулями, выносятся в `shared/types/`.
- **Обработка состояний** (`loading`, `error`, `empty`) выполняется на уровне компонента.

## 5. Маршрутизация

- **React Router 7, Declarative mode:** `BrowserRouter` + `Routes` + `Route`.
- **Все маршруты** определены в `app/router.tsx`.
- **Редиректы:** `/` → `/catalog`.
- **Несуществующие URL (`*`)** → страница `NotFound` с ссылкой на каталог.
- **Страницы не содержат `<Route>`** — только компоненты. Маршрутизация централизована в `app/`.
